# Keylogger Simulation & Detection (EHA361 - Milestone 1)

## 📋 Overview
Educational demonstration of keylogger attack simulation and defensive detection in an isolated VirtualBox lab environment.

## 🎯 Objectives
- Simulate keylogger behavior in controlled environment
- Detect the simulated keylogger using security scripts
- Document defensive security measures

## 🛠️ Technologies Used
- Kali Linux (Attacker VM)
- Ubuntu Linux (Target VM)
- Bash scripting
- PowerShell
- Python HTTP server

## 🔧 Key Actions
1. Pre-attack defensive security scan
2. Simulated keylogger file creation
3. Detection script deployment
4. Security reporting
